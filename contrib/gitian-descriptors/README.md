# Gitian descriptors — not used for Zero

These files are **legacy upstream artifacts** (Bitcoin / Zcash–era reproducible builds). **Zero does not run Gitian** for releases; the paths and remotes in the descriptors are **not maintained** and must not be treated as a build recipe.

**Use instead:** normal **`depends/`** + **`zcutil/build.sh`** (see **BUILD_ZERO.md**), plus project release practices in **UpdateZero.md** §6 and §13.
