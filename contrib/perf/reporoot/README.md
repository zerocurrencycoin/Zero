# reporoot -- drafts for Zero-owned material

Proposed changes to documents and code that Zero owns and this tree does not
edit. Each draft names the Zero target, is compared against a stated Zero
commit, and holds only what is still pending; an applied proposal is removed
from its draft, and a draft with nothing pending is deleted. `PLAN.md` group
Z tracks them.

| Draft | Zero target |
|-------|-------------|
| `MAINTREE_CHANGES.md` | `src/` and `qa/` changes made in this tree, for review |
| `TODO.proposals.md` | `TODO.md` entries |
| `DOC-CONVENTIONS.md` | Replacement for the `UpdateZero.md` DOC-CONVENTIONS entry |
| `MIGRATION_PLAN.md` | Satellite repositories; owner note, not a `TODO.md` item |
