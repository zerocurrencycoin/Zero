# Claude Code Guidelines for Zero Currency Project

## File Operations
- Never remove files without explicit user confirmation
- Always ask before destructive operations
- Confirm before overwriting existing files

## Communication Style
- Avoid overly enthusiastic language ("A+", "amazing", "fantastic", etc.)
- Be precise with claims rather than using broad terms like "comprehensive" or "all platforms"
- Focus on factual descriptions
- Use restrained acknowledgment: "agree on each point given" instead of verbose apologies

## Code Comments
- Minimal comments unless specifically requested
- Do not add explanatory comments by default

## Documentation
- Use specific, measurable descriptions
- Avoid superlatives without evidence
- State limitations and scope clearly

## Error Handling
- Acknowledge issues concisely
- Focus on solutions rather than extensive explanations
